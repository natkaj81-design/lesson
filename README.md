# Безпечне користування Інтернетом — інтерактивний урок

Односторінковий навчальний сайт українською мовою на основі теми уроку «Безпечне користування Інтернетом. Критичне оцінювання відомостей, отриманих з Інтернету».

## Що є на сторінці
- короткий теоретичний блок про безпечну поведінку;
- критерії оцінювання вебсторінок: навігація та зручність, авторство, надійність змісту;
- компетентнісне завдання з проблемною ситуацією, полями для відповідей і орієнтиром для самоперевірки;
- тест із 6 запитань, автоматичним підрахунком балів і поясненнями;
- рефлексія та можливість друку/збереження сторінки в PDF.

## Як опублікувати на GitHub Pages
1. Створіть репозиторій на GitHub, наприклад `internet-safety-lesson`.
2. Завантажте файл `index.html` у кореневу папку репозиторію.
3. За бажанням завантажте також цей `README.md`.
4. Відкрийте **Settings → Pages**.
5. У розділі **Build and deployment** оберіть **Deploy from a branch**.
6. Як джерело виберіть гілку `main` і папку `/(root)`, натисніть **Save**.
7. Після публікації GitHub покаже адресу сторінки у розділі Pages.

Сайт не потребує серверу, бібліотек або API: HTML, CSS і JavaScript уже містяться в одному файлі. Відповіді учнів не надсилаються в Інтернет і не зберігаються на сервері.
